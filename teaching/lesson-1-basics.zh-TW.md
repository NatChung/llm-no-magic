# Lesson 1 — Tab ① 接龍:token 與機率分佈

> English: [lesson-1-basics.md](./lesson-1-basics.md)

## 學習目標
1. 知道 model 是「一個 token 一個 token 接龍」,每步從機率分佈抽樣
2. 會讀 top-10 bar chart:peaked(很有把握)vs flat(不知道接啥)
3. 體會 **peaked ≠ 真實**:confidence ≠ correctness

## 開場(不問答,直接帶入 demo)

一句話帶過:model 是「一個 token 一個 token 接龍」,每步從機率分佈抽樣;等下用 top-10
長條圖看 model 有沒有把握——peaked(篤定)vs flat(沒把握),還有一個重點:**peaked ≠ 真實**。

## Demo 段落

### 段落 1 — model 記得的文本(peaked)
- 預告:「我讓瀏覽器自己動:送『床前明月光,疑是地上』給一個 0.6B 小 model,看它接下一個字。注意右邊機率圖。」(先收學員預測:下一個字是什麼?)
- 驅動:`POST /drive {"tab":"1","user":"床前明月光,疑是地上"}` → 學員頁面自動切到 Tab ① 並逐 token 渲染
- 讀回應:首 token「霜」、top-1 94%+,分佈 peaked → 旁白:它「背過」整首詩 → peaked
- 點深看:`POST /inspect {"tokenIndex":0}` → 學員頁面彈該 token 機率圖
- **一定要說**:畫面上生成出來的每個字都可以用滑鼠點,不是只有這個——想看其他字當下的機率,自己戳戳看就會彈圖(後面段落不用每次重講,但這裡要先讓學員知道)

### 段落 2 — 瞎掰的星球(peaked ≠ 真實)
- 預告:「這次送 `祖樹星上最高的山叫做什麼？` — 祖樹星是瞎掰的星球。你猜:model 會說『不知道』,還是編一個山名?」(先收學員預測!)
- 驅動:`POST /drive {"tab":"1","user":"祖樹星上最高的山叫做什麼？"}` → 學員頁面自動切到 Tab ① 並逐 token 渲染
- 讀回應:首 token 仍高信心編一個山名 → 旁白:照樣高 confidence 編 → peaked ≠ 真實
- 點深看:`POST /inspect {"tokenIndex":0}` → 學員頁面彈該 token 機率圖
- **深挖(視當次生成而定,不用照本宣科)**:比對逐 token 的 prob 會看到——「答」「案」「是」這種句型骨架信心 90%+,但真正編內容的那個字(例如瞎掰出的山名第一個字)常常掉到個位數 %,是全場最低點之一。這比「peaked ≠ 真實」更精準一層:model 瞎掰的**當下其實是猶豫的**(那一步是 flat 分佈),只是抽樣機制照樣得選一個字,選完之後才順著句型接得篤定、甚至自己肯定「答案正確」。這現象不保證每次都出現(取決於當次抽樣結果),如果學員自己發現、或你看數據時剛好對到,順勢帶出來即可

### 段落 3 — 不知道接啥(flat)
- 預告:「『他打開冰箱,拿出一包』— 你猜 top-10 會長怎樣?」
- 驅動:`POST /drive {"tab":"1","user":"他打開冰箱,拿出一包"}` → 學員頁面自動切到 Tab ① 並逐 token 渲染
- 讀回應:top-10 分散(糖果/薯片/巧克力/牛奶…),top-1 只一成多 → 旁白:分佈形狀 = model 把握度
  (只打到「拿出」top-1 仍有 27%,不夠有感;多打量詞「一包」逼它猜具體物品,分佈才夠平)
- 點深看:`POST /inspect {"tokenIndex":0}` → 學員頁面彈該 token 機率圖

## 學員動手
請學員自己:換一句 prompt 重打、點不同 token 看分佈跳動;進階 — 打一句只有他們公司
才知道的事實開頭,看 model 怎麼自信亂編(自製祖樹星)。

## 揭曉與回顧
- 連到段落 2 瞎掰星球的例子:如果拿它回客訴信,它會亂承諾不是「壞」,是**它缺你公司的
  退款政策**,只能機率接龍、還接得很篤定 — 亂回不是「GPT 不能信」,是「它缺那塊知識」
- **收尾接龍(帶出下一課)**:再驅動一次 Tab ① — `POST /drive {"tab":"1","user":"一年有幾個月?"}`。
  這是一句正常的問句,但純接龍模式下 model 不會「回答」它,只會照著文字接下去、卡進跳針迴圈,
  從頭到尾沒答出「12」。
- **跳針 demo 後,先問學員(收預測,不給答案)**:「同一顆接龍引擎,你猜要怎麼弄,才能變成
  你熟悉的那個 ChatGPT — 會好好回答客戶問題的那個?」讓學員自由猜(常見猜法:換更大的
  model、加了搜尋、有個判斷是不是問句的模組⋯⋯)。記下他們的猜測,下一課的 demo 會直接
  驗證或推翻它 — 這比直接預告「中間多了一層」更有力。
- 跟學員說:**記住這句「一年有幾個月?」— 下一課同一句會自動跟著你到下一個分頁**
  (切過去時會自動帶進輸入框),我們就從這句看「接龍怎麼變成問答」,順便對答案 → Lesson 2

## 常見學員問題
- 「它是不是查了資料庫?」— 沒有,純接龍;你剛看到每一步的候選了
- 「0.6B 太笨吧?ChatGPT 也這樣?」— 大 model 分佈更準,但機制一模一樣,也一樣會自信亂編
- 「為什麼同 prompt 每次答的不同?」— 抽樣;top-1 不是唯一會被選的
